# Meridian Traffic Computer — improved

Fictional autonomous-EV traffic-computer visualization. Not Tesla software — no Tesla assets, icons, layouts or sounds.

**Play:** https://arecibo-sys.github.io/tesla_sonnet5.5_improved/

Procedural 3D road scene: traffic with car-following and lane changes, working signals, pedestrians, hazards, rain/fog/night, tunnel and bridge, and a readable ego driving state machine. Runs on desktop and mobile Safari/Chrome; audio starts on a user gesture.
